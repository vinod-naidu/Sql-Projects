🗳️ Indian Election Result Analysis using SQL
📌 Project Overview

This project focuses on analyzing Indian General Election Results using SQL.
The dataset contains detailed information about constituencies, political parties, candidates, states, vote counts, and alliances.

The project demonstrates how SQL can be used for:

Data analysis
Election insights
Vote distribution analysis
Party performance tracking
State-wise and constituency-wise reporting

The database is designed using a relational schema with multiple interconnected tables.

🚀 Features
Total seats analysis
State-wise seat distribution
NDA vs I.N.D.I.A alliance comparison
Party-wise performance analysis
Constituency-level winner analysis
EVM votes vs Postal votes analysis
Top candidates by votes
SQL joins, aggregations, subqueries, and case statements
